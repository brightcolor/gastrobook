# Neue Oberfläche, Teil 3: Öffnungszeiten, Ausnahmen, Abbau der Sammelseite – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die letzten beiden Einstellungsseiten (Öffnungszeiten mit Vorschau, Ausnahmen mit „Sperren…“) entstehen, die alte Sammelseite `/admin/settings` und `SettingsController` gehen, alte Adressen und Sprungmarken führen auf die neuen Seiten, ein Zuordnungstest belegt, dass jede alte Einstellung genau einen Platz hat, und Handbuch und Changelog beschreiben den neuen Stand. Danach ist `new-ui` bereit zum Zusammenführen mit `main`.

**Architecture:** Wie in 2b/2c: je Seite ein Controller unter `App\Http\Controllers\Admin\Settings\*`, eine Ansicht unter `resources/views/admin/settings/*`, Antworten über `RespondsToSettingsForms`. `TimeSlotService` bekommt eine Methode, die mit übergebenen Zeitfenstern rechnet; `slotStarts` nutzt sie, die Vorschau ebenso. Ausnahmen schreiben in die bestehenden Tabellen `special_opening_hours`, `blackout_periods` und `table_blocks`; eine neue Spalte `exception_group` hält zusammen, was eine Ausnahme angelegt hat. Ein Dienst `App\Services\ScheduleExceptions` liest, schreibt und beschreibt Ausnahmen; der Controller bleibt dünn. Die Einstiegsadresse `/admin/settings` leitet auf die erste erlaubte Seite; ein kleines Modul übersetzt alte Sprungmarken.

**Tech Stack:** Laravel 13, PHP 8.3, Blade, Tailwind CSS 4 (Vite), Vanilla-JS als ES-Module, Vitest + jsdom, PHPUnit (SQLite und PostgreSQL 17), Pint, PHPStan.

**Spec:** `docs/superpowers/specs/2026-10-07-new-ui-admin-design.md` (Abschnitte „Öffnungszeiten“, „Ausnahmen“, „Zuordnung alt → neu“, „Einstellungen aufteilen“, „Tests“, „Abnahme“)

<?php

declare(strict_types=1);

namespace Tests\Feature;

use App\Models\OpeningHour;
use App\Services\TimeSlotService;
use Carbon\CarbonImmutable;
use Illuminate\Foundation\Testing\RefreshDatabase;
use PHPUnit\Framework\Attributes\DataProvider;
use Tests\Concerns\CreatesTenants;
use Tests\TestCase;

class OpeningHoursPreviewTest extends TestCase
{
    use CreatesTenants, RefreshDatabase;

    /** @return array<string, array{0: string, 1: string, 2: int, 3: int}> */
    public static function windows(): array
    {
        return [
            'Abend' => ['17:30', '22:00', 30, 90],
            'über Mitternacht' => ['20:00', '01:30', 15, 150],
            'zu kurz' => ['12:00', '12:45', 20, 60],
            'Takt 45' => ['11:00', '15:00', 45, 60],
        ];
    }

    #[DataProvider('windows')]
    public function test_preview_matches_the_booking_page(string $opens, string $closes, int $interval, int $duration): void
    {
        $setup = $this->createTenantSetup();
        $setup['location']->settings()->update(['slot_interval_minutes' => $interval, 'default_duration_minutes' => $duration]);
        $owner = $this->createMember($setup['tenant'], 'tenant_owner');
        $tz = $setup['location']->timezone;
        $day = CarbonImmutable::now($tz)->addWeek()->startOfDay();
        $weekday = $day->dayOfWeekIso - 1;
        OpeningHour::where('location_id', $setup['location']->id)->where('weekday', $weekday)->update(['opens_at' => $opens, 'closes_at' => $closes]);
        $expected = array_map(
            fn (CarbonImmutable $s) => $s->format('H:i'),
            app(TimeSlotService::class)->slotStarts($setup['location']->fresh(), $day, $duration),
        );
        $this->clearTenantContext();

        $response = $this->actingAs($owner)->postJson('/admin/settings/opening-hours/preview', [
            'weekday' => $weekday,
            'windows' => [['opens_at' => $opens, 'closes_at' => $closes]],
        ])->assertOk();

        $this->assertSame($expected, $response->json('starts'));
        $this->assertSame($expected === [] ? null : end($expected), $response->json('last'));
    }

    public function test_reason_names_closing_time_and_duration(): void
    {
        $setup = $this->createTenantSetup();
        $setup['location']->settings()->update(['slot_interval_minutes' => 30, 'default_duration_minutes' => 90]);
        $owner = $this->createMember($setup['tenant'], 'tenant_owner');
        $this->clearTenantContext();

        $response = $this->actingAs($owner)->postJson('/admin/settings/opening-hours/preview', [
            'weekday' => 4,
            'windows' => [['opens_at' => '18:00', 'closes_at' => '22:00']],
        ])->assertOk();

        $this->assertSame('20:30', $response->json('last'));
        $this->assertSame('Letzte Uhrzeit 20:30: Ein Besuch dauert 90 Minuten, um 22:00 wird geschlossen.', $response->json('reason'));
    }

    public function test_groups_with_their_own_duration_get_their_last_time(): void
    {

    /**
     * Zeitfenster eines Tages aus Uhrzeiten, etwa aus einem noch nicht
     * gespeicherten Formular. Gleiche Form wie windowsForDate().
     *
     * @param  array<int, array{opens_at: string, closes_at: string, service_name?: ?string}>  $times
     * @return array<int, array{opens: CarbonImmutable, closes: CarbonImmutable, label: ?string}>
     */
    public function windowsFromTimes(CarbonImmutable $localDate, array $times): array
    {
        return array_map(
            fn (array $t) => $this->makeWindow($localDate, $t['opens_at'], $t['closes_at'], $t['service_name'] ?? null),
            array_values($times),
        );
    }

    /**
     * Startzeiten in den Fenstern: ab Öffnung im Takt, solange die ganze
     * Dauer vor dem Schließen Platz hat.
     *
     * @param  array<int, array{opens: CarbonImmutable, closes: CarbonImmutable, label: ?string}>  $windows
     * @return array<int, CarbonImmutable>
     */
    public function startsForWindows(array $windows, int $durationMinutes, int $intervalMinutes): array
    {
        $starts = [];
        foreach ($windows as $window) {
            $cursor = $window['opens'];
            $lastStart = $window['closes']->subMinutes($durationMinutes);
            while ($cursor->lte($lastStart)) {
                $starts[] = $cursor;
                $cursor = $cursor->addMinutes($intervalMinutes);
            }
        }

        $starts = array_unique($starts, SORT_REGULAR);
        usort($starts, fn ($a, $b) => $a->timestamp <=> $b->timestamp);

        return array_values($starts);
    }
